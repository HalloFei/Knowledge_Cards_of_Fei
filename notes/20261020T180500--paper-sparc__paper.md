# 标得对不对，要问机器人做了什么

**副标题**: SPARC: Reliable Spatial Annotations from Robot Demonstrations at Scale（给机器人示范自动打空间标注，并给每条标注一个可校准的可信度分数）

**日期**: 2026-10-20

**来源**: https://arxiv.org/abs/2606.13497

**作者**: Nils Blank, Paul Mattes, Maximilian Xiling Li, Jakub Suliga, Thomas Roth, Moritz Reuss, Pankhuri Vanjani, Rudolf Lioutikov

**发表场所**: arXiv preprint（2026-06 提交，v2 2026-10）

---

## 速读

一段"把瓶子放到香料架上"的演示，夹爪合上的那几十帧里，检测器把最高分框套在了夹爪自己身上；而正确答案那只瓶子，有三成以上压在夹爪的掩码里——同一帧、两个候选、判决相反，长得几乎一样。原来的管线只信一个数：检测置信度。它答的是"这块像不像我说的那个词"，不是"这块是不是机器人这一段真正动过的那一个"。SPARC 把打分换成从动作里取证：相位内的运动决定这一段选谁，检测置信度只负责在全体之间定档，机器人重叠只用来否决、而且必须软。它多看见的是一件事——一个分数要干两个活（段内选谁、跨段排谁），两个活要的刻度不一样，混在一起就两个都坏。判断因此变了：问题不是"能不能标得更准"，而是"同一个精度门槛下能留下多少条"；它留下 58%，最强的轨迹过滤基线只剩 20%。

## 它到底在解决什么

把那一帧放大。一只手握着瓶子，夹爪闭合着，任务是把它放到香料架上。自动标注要回答的问题是：这些框里，哪一个是"被操作的那个物体"。候选有两个——夹爪，和瓶子。

检测器把最高分给了夹爪。这不算荒唐：夹爪在这一帧里最居中、最显眼，在整段视频里也动得最多。论文自己把这个失败模式写在正文里：夹爪"往往动得最多，在检测提议里也最显眼"。而瓶子不是"在夹爪旁边"，它是"在夹爪里面"——论文把"与机器人的重叠超过三成"当作一类样本来统计，能解出来的演示里约占 6%。

于是同一帧出现一个很别扭的局面：两个候选，判决必须相反；而唯一能做出这个判决的线索，"它跟机器人重叠了多少"，同时指着两个。

老做法是给检测置信度卡一个阈值，再串一个跟踪器把框传下去。这条路失灵不是因为不准，是因为答错了题：置信度回答"这块区域像不像我说的那个词"，标注的对错问的却是"这块区域是不是机器人在这一段里真正动过的那一个"。前者关于长相，后者关于事件。而在杂乱场景里，这两个问题不是随机分岔，是系统性地分岔——越是被真正操作的东西，越会被手或夹爪遮住；越显眼、动得越多的东西，越可能正是机器人自己。

第二条老路是拿运动幅度过滤，只在轨迹足够长时保留。它在很大一部分样本上干脆弃权——在零样本的那一批上过了半数——弃权让排序指标看起来漂亮，代价是半个语料库没了。第三条是人工复核，一条三十几秒，自动管线五秒，差一个数量级。

所以卡点不在"检测器不够好"。卡点在两件还没被分开的事：这个数在回答长相，而我们需要它回答事件；以及，就算它开始回答事件，它还得同时干两件不同的事。后一件先不展开。

## 它真正看见了什么

一句话：一条标注对不对，是"机器人在这一段里动了哪个东西"这个事实；所以给它打分的证据只能来自动作，而动作给出的证据有两种职务——在本段里挑出那一个，和在所有段里排出可信度——这两种职务要的刻度不一样。

先补最小的那个概念：**相位**。它指夹爪从合上到松开的那一段，加上前后靠近与释放两段。它不是"视频里的某一段"，也不是"物体动得厉害的那几帧"。它的作用是把"动了"这个词变得有指向：瓶子在整段视频里一直在动，因为相机在动、手臂在动、旁边那张纸巾也在动；真正说明问题的是"夹爪合上之后它动了，之前和之后它没怎么动"。论文把它写成一个信噪比：夹爪忙的时候它的平均位移，除以夹爪闲着的时候它的平均位移——分母存在，背景和抖动才不会被当成操作。

相位不是打分时才用到的一个项，它是整条管线的坐标系。在哪一帧去做检测（取第一次抓取相位的中间，让物体和夹爪互相少挡一点）、哪一段算"交互中"、哪些帧算"夹爪在旁边"，都由它定。所以后面会看到，相位一旦没了，整条链子不是掉几分，是换了一种性质。

这里马上出现第一个反直觉的地方。这个信噪比是**在同一段演示的所有候选之间**做归一化的：它只回答"这一段里谁最像被操作的那个"，不回答"这一段的标注整体靠不靠谱"。检测置信度是另一回事——它不做段内归一化，所有演示共用一个刻度。这个差别看着像工程细节，其实是整篇文章的枢轴。

论文的分角色表把它照了出来：相位内运动单独用，是最强的选人者，选对的比例比检测置信度还高；可它把对的与错的排序的能力几乎是瞎的。检测置信度反过来，单独选人很弱，却是最强的排序者。把检测置信度从总分里拿掉，选对的准确率只掉一点点，"在 90% 精度上还能留下多少"却掉了一小半。同一张表里还有一处更干净的反转：换一个开放词表检测器（OWLv2），它整体选对的准确率比论文最终用的那个还高，可在 90% 精度这条线上几乎一条都留不下（0.2%）。检测更准的那个，反而更不会排序。论文挑检测器时挑的是"分数更可校准"的那个，不是"更准"的那个——这个选择本身就是对旧尺子的判决。

（一句分寸：为什么段内归一化会让运动失去跨段可比性，论文只说了检测置信度好在"刻度跨演示可比"，反过来那一半是我从它的归一化方式读出来的；表里的取舍则是实测的。）

第三个概念是**反证据**。机器人重叠这一项从来不肯定任何东西，它只说"这不是物体，这是机器人"。它和选人者的区别不是强弱，是方向：选人者问"哪个最像被操作的"，反证据问"哪个根本不是东西"。所以它们不能互相替代，只能并列。而它必须软，理由就在开头那一帧：被握住的东西本来就和机器人重叠，一个硬阈值会把正确的答案一起杀掉。论文数过这件事——硬过滤确实误杀了一批本来正确的候选，占可解样本的个位数百分比，其中约一半在没有硬拦的情况下本来是对的。

救回来的机制是**深度豁免**：候选与夹爪尖的深度差越大，重叠的扣分越轻。用锚点说就是，夹爪自己离夹爪尖是零距离，而瓶子有厚度——它可能贴在夹爪上，但它不完全在夹爪那个深度上。这一条只在该生效的地方生效：在正确框压在机器人身上那批样本里，把深度豁免拿掉，准确率掉两成、覆盖率几乎清零；在其余样本上几乎看不出差别。这是论文自己做的分层消融，不是我的推断。

把三条接起来：

```text
   同一段演示内（本段可比）              跨演示（绝对刻度）
   ┌──────────────────────┐        ┌──────────────────────┐
   │ A 相位内运动          │        │ D 检测置信度          │
   │ P 夹爪邻近            │        │ 不归一，跨段同一把尺  │
   │ 段内 min-max 归一     │        │                      │
   └──────────┬───────────┘        └──────────┬───────────┘
              │  选：这一段里是哪一个            │  排：这条值不值得留
              └──────────────┬───────────────┘
                             ▼
                   R 排序 → 卡阈值 → 留多少条
                             ▲
           Π 机器人重叠 ──────┘  只否定；离夹爪尖越远扣得越轻
```

用它跑一遍开头那一帧。夹爪在段内动得最多，运动的归一化分会把它顶到第一；瓶子紧随其后；重叠项对两者都扣，但夹爪离夹爪尖零距离，扣满，瓶子的深度差豁免了大部分。于是选出来的是瓶子。而整条标注的分数主要由检测置信度定档——它保证这一条在全体排序里落在能被 95% 精度门槛留下的位置。两个职务各干各的，缺一个就出前面那种局面。

现在换条件。第一个变化论文里有现成对照，而且很锋利：把相位弄脏——边界不准、偶尔多切一刀——几乎不掉；把相位拿掉，比如推、擦这类没有夹爪闭合的动作只能退化成"整段一个交互相位"——准确率明显掉一截，覆盖率也掉，但仍明显高于检测置信度。这两件事的差别说明模型依赖的不是相位的**精度**，是相位的**对比**：只要有"忙"和"闲"两段，信噪比就有分母；一旦只剩一段，分母消失，这个信号退化成"整段动了多少"，也就是那条已被证明不好用的老路。

第二个变化更狠，是按钮与按压：接触是静止的，位移几乎为零。这时运动的分子分母一起塌掉，选人者失去信息；表里可以看到，给它加上运动这一项，准确率反而从三成掉到一成半——比不加还差。同样在这类任务上，把深度豁免和运动项拿掉，准确率反而是升的。这条证据只有十三个样本，不能当结论，但它指出的方向很清楚：当交互本身不产生位移时，缺的不是权重，是另一种模态（作者建议用力矩或触觉的接触事件替代视觉相位）。

到这里可以说清这个模型最多证明什么。它测到的是：在 IA-Bench 这套人类标注的起止框上（对错按框重叠超过四成算），这套打分在 90% 精度线上留下的样本远多于任何单一信号，而且这个分数在完全没参与调参的那批数据上不重新校准也能用。它没有测到的是：为什么是这套权重。论文自己在附录里承认，那个"检测置信度权重随夹爪邻近自动下降"的设计听着聪明，换成固定权重结果几乎一样（0.803 对 0.802）；用逻辑回归学一个组合反而更差。所以真正的承重结构是几个线索的**职务分工**，不是那个精致的加权公式。

下游那一段要克制地读。用这套标注训出来的 4B 模型在指向类基准上超过了用人类标注数据训的同尺寸模型，真机杂乱桌面上的成功率比用检测标注训的那版高一倍多；作者把增益归给"抓对了物体"，因为定位正确的比例同步涨到三倍。这是作者的解释，与数据一致，但没有把"标注质量"和"数据配方"完全隔开。更硬的一条是缩放曲线：按检测置信度排序，样本加到八十多万条时两条曲线都往下走；按这套分数排序，在 IA-Bench 上一直涨到那个规模，只是总榜在二十万条之后也开始回落——作者把那一部分归因于没混通用数据导致的过拟合。

## 我能带走什么

一条规则：以后看到一条自动标注管线报"置信度"，先不问它有多准，先问这个数是拿什么算的——是"像不像"，还是"动没动"；再问它要干哪个活——是在一堆候选里挑一个，还是在全体里排个队。这两个活要的刻度不一样，一个数同时干，通常意味着其中一个已经悄悄失效了。

两个用法。看数据管线的质量报告时，别只看准确率，看"在你能接受的精度门槛上还能留下多少"——很多管线在准确率上不差，在覆盖率上接近零，等于不能用于高精度场景。看任何"用物理信号校验感知结果"的设计时，先找它的否定项怎么处理：如果它对"和机器人重叠"是一刀切的，那它一定会杀掉被握住的正确物体，只是杀掉多少的问题。

这篇论文给的是一把尺子的用法，不是施工图：它把"标注可信度"从长相问题改成了事件问题，代价是必须先把动作切成相位，而切不出相位的那类任务，它自己承认还没解决。
