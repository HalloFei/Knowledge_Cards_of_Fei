# 放大模型前，先保住信噪比

**副标题**: LLMs as Noisy Channels: A Shannon Perspective on Model Capacity and Scaling Laws（把大语言模型当作有噪声的信道，用香农定理给"模型容量与缩放规律"一个统一解释）

**日期**: 2026-10-10

**来源**: https://arxiv.org/abs/2605.23901

**作者**: Xu Ouyang, Deyi Liu, Yuhang Cai, Jing Liu, Yuan Yang, Chen Zheng, Thomas Hartvigsen, Yiyuan Ma

**发表场所**: arXiv preprint，2026

---

## 速读

业界默认"越大越好"：参数越多、数据越多，loss 就越低。但现实里出现了反例——模型更大、训得更久，下游任务反而更差（灾难性过训练、量化退化），loss 曲线不是一路向下，而是先降后升的 U 形。这篇论文缺的那个概念是"信噪比"：它把 LLM 训练看成在一条有噪声的信道上传信息，容量 = 带宽 × log₂(1 + 信噪比)，loss 是容量的倒数。放大模型或数据，只有同时保住信噪比才带来增益；否则噪声比信号涨得快，容量塌缩、loss 回升。所以我以后看到任何"加大模型 / 加数据"的方案，先不问"够不够大"，先问"这次放大有没有同时放大噪声、信噪比保不保得住"。

## 它到底在解决什么

一个外行也能看见的反常：你花更多钱把模型做大、喂更多数据，结果下游任务的表现反而变差。Springer 等人发现"灾难性过训练"——预训练做得越久，下游微调反而越差；另一些工作发现"量化退化"——更大或训得更充分的模型，在低比特量化后反而更容易崩。这两件事长成同一种形状：loss 先降后升，一条 U 形曲线。

原来人们怎么处理：用单调幂律去拟合。OpenAI 律、Chinchilla 律都假设 loss 只降不升，只能画出单调曲线，表达不了"越过某个阈值后变差"。后来有人往幂律上加一个"退化惩罚项"来救 U 形，但那是往单调公式上打补丁——量化、过训练各打一个，没有统一解释为什么"更大"有时是好事、有时是坏事。

旧理解缺的关键区分：它把"资源投入"和"有效信号"当成一回事，没有区分信号与噪声，也没有区分带宽与信噪比。于是它解释不了"同样的放大动作，为什么结果会反转"。

## 它真正看见了什么

一句人话：训练 LLM 是在一条有噪声的信道上传输信息，模型容量受香农容量约束——容量 = 带宽 × log₂(1 + 信噪比)，loss 是容量的倒数。

先把"信道容量"这个概念立起来。香农-哈特利定理说，一条有噪声的信道能无错传输信息的速率有一个上限 C = B·log₂(1 + S/N)。它不是"实际速率"，也不是"带宽本身"：带宽再宽、信号再强，噪声一多，容量照样被压下来。容量由带宽和信噪比两样东西共同决定。论文把"LLM 能学多少知识"直接套进这个上限。

然后是映射，这是全文的骨架：

- **带宽 ↔ 模型大小 N**（N^α）：更大的模型有更大的参数空间，像更宽的频带能装更多信息。
- **信号 ↔ 训练 token D**（D^β）：语料里的知识就是信号。
- **噪声 ↔ 三个来源**：数据噪声 d·D^δ（语料里的错别字、歧义、矛盾，随 token 累积）、模型交互噪声 c·(D·N)^γ（训练本身是去噪过程，模型越大越久，内在噪声也在变）、不可约噪声 e（架构本身的熵，常数）。

核心关系是信噪比，把它写成最小公式：

C = a·N^α · log₂( 1 + b·D^β / ( c·(D·N)^γ + d·D^δ + e ) )

翻译成人话：模型容量 = 模型大小的某个幂，乘以 log₂(1 + 信噪比)；信噪比 = token 带来的信号，除以（模型交互噪声 + 数据噪声 + 不可约噪声）。注意这里的双重角色——加数据 D 既加信号（分子）也加数据噪声（分母），加模型 N 既加带宽也加交互噪声。所以"放大"本身不保证变好，取决于谁涨得快。

信噪比（SNR）的定义与算法：SNR = 信号功率 ÷ 噪声功率，在这里就是 b·D^β / ( c·(D·N)^γ + d·D^δ + e )。它不是从数据里直接测出来的物理量，而是作者定义在公式里的结构——9 个常数靠拟合 loss 反推出来，所以 SNR 是间接标定的中间量，不是独立测量。决定它的只有三类输入：token 数 D（同时加信号和噪声）、模型大小 N（同时加带宽和交互噪声）、扰动强度 X（量化位宽、学习率、注入噪声，压低 SNR）。

这也划清了"能不能靠清洗来降噪"的边界：数据噪声 d·D^δ 对应真实可清洗的东西（错别字、歧义、矛盾、低质量语料），扰动 X 也可直接控制（更高精度、更低学习率）；但模型交互噪声 c·(D·N)^γ 是训练动力学的抽象，不可约噪声 e 是架构下限，都不是"脏东西"，洗不掉。而且拟合显示 δ 恒大于 β——即便数据很干净，噪声仍随 D 累积，清洗只能抬高 U 形出现的阈值，不能把缩放变回单调。

最后用倒数把容量翻译成可观测的 loss：loss = 1 / 容量。容量越大 loss 越小，容量趋近 0 时 loss 爆炸。有了这一步，公式才能被拟合和检验。

| 放大什么 | 它同时喂大了什么 | 结果由谁决定 |
|---|---|---|
| 模型大小 N | 带宽（好事）+ 交互噪声（坏事） | α 与 γ 谁大 |
| 训练 token D | 信号（好事）+ 数据噪声（坏事） | β 与 δ 谁大 |

把这些概念接成一个最小模型：输入是模型大小 N、token 数 D（以及扰动强度 X），它们先决定带宽和信噪比，信噪比决定容量，容量的倒数就是 loss。于是它能区分一个邻近情况——两个看起来都是"加大模型"的案例，结果相反，差别只在信噪比：高 SNR 时带宽指数 α 大于模型噪声指数 γ，增益压过噪声，越大越好；低 SNR 时 γ 反超 α，噪声涨得比带宽快，越大越差。数据轴上 δ 恒大于 β，意味着数据轴上的 U 形是内生的，不是扰动带来的。

改变一个条件：把扰动强度 X 加大（量化更狠、学习率更高、加高斯噪声），噪声项变大，SNR 下降，最优区域从一片开阔地收窄成一个 basin，单调幂律彻底失效。论文在 Pythia 和 OLMo2 上，用高斯噪声（40→10 dB）、SFT（数学 / 问答 / 代码，不同学习率）、量化（4 / 3 / 2 bit）三组扰动验证了这一点。

证据贴着主张：在 2-bit 量化下，单调幂律的 R² 塌到约 0.72（Pythia）/ 0.61（OLMo2），Shannon 律保持在 0.96 / 0.89——它抓住了 U 形，而幂律只能画单调线。更强的证据是外推：只用 ≤6.9B、≤180B token 的 Pythia 拟合，预测没见过的 12B 模型到 307B token，pooled R² = 0.847，而 Chinchilla 掉到 0.305、OpenAI 变负——这说明公式不是过拟合，而是抓住了 N 和 D 的联合结构。消融也支持结构：把交互噪声 c(D·N)^γ 换成只含 N 的项，在 10dB 强噪声下拟合明显变差，说明"模型噪声随 token 也涨"这一项是必要的。

适用范围就地说明：信噪比是类比映射，不是物理测量——把 N、D 映射成带宽、信号、噪声是作者的理论假设，噪声项没有独立测量，属于结构推演；外推只在 Pythia 一套上验证，1.7× 之外还没证明；这是拟合缩放律，不是因果机制证明，它把 U 形变得可拟合、可预测，但没证明信噪比就是造成 U 形的物理原因。

## 我能带走什么

一条可复用判断规则：以后看到"加大模型 / 加数据 / 更狠训练"的 scaling 方案，先不急着判断"更大更好"，先问——这次放大有没有同时放大噪声，信噪比保不保得住。若放大的是低精度、高学习率、噪声数据这类会压低 SNR 的条件，更大反而可能更差。

一个真正相关的用法：判断一条缩放律够不够用，先看它能不能表达 U 形——有没有噪声项。只在干净数据上比 R² 不够，要看它在强扰动下会不会塌；一条只能画单调曲线的律，注定在越过阈值后失效。
