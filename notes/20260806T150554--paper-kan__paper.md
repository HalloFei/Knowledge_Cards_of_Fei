# 把神经网络的权重炼成可读公式

**副标题**: KAN: Kolmogorov-Arnold Networks

**日期**: 2026-08-06

**来源**: https://arxiv.org/abs/2404.19756

**作者**: Ziming Liu, Yixuan Wang, Sachin Vaidya, Fabian Ruehle, James Halverson, Marin Soljačić, Thomas Y. Hou, Max Tegmark

**发表场所**: arXiv / 2024

---

## 速读

一个只有 200 个参数的 KAN，在纽结理论任务上不仅准确率超过 DeepMind 此前用 30 万参数 MLP 达到的水平，还能让人直接「看见」网络的判断依据——因为它的结构本身就是公式。这篇论文做了一件事：把神经网络里固定的激活函数（ReLU、SiLU）从节点上拆下来，换成可学习的样条函数，装到每条边上去。这个移动让「学了什么」从一坨无法阅读的权重矩阵，变成了一组一维的、可以画出来、进而可以符号化的函数曲线。从此以后，判断一个神经网络是否真正学会了某个关系，不该只看准确率，而该问：剪枝后剩下的结构能不能写成一个我能理解的公式。

## 它到底在解决什么

先看一个具体场面。2021 年，DeepMind 的团队想用神经网络发现纽结理论里代数不变量和几何不变量之间的关系。他们搭了一个 4 层、每层 300 个神经元的 MLP，用 17 个纽结不变量作为输入来预测签名（signature）。准确率达到 78%，不算差。但问题是：这个网络为什么这样判断？它到底看了哪些输入变量？团队必须借助梯度显著度（gradient saliency）这类归因方法，才能大致猜出网络主要依赖了 meridional translation 和 longitudinal translation 这两个量。后续人类数学家又花了不少功夫，才从这些线索中推导出一个符号公式。

这个故事暴露了 MLP 作为科学发现工具的根本困境。MLP 的训练结果是一堆数字——权重矩阵里的浮点数。你可以用这些数字做前向传播得到答案，但你无法阅读它们。为了理解网络学会了什么，你需要额外的归因工具，而归因工具给出的只是相关性信号，不是因果结构。更要命的是，MLP 的激活函数（ReLU、tanh、SiLU 等）是全局的——任何一个输入的变化都可能影响所有下游神经元，导致局部修改不可控。这就是为什么 MLP 在持续学习任务中会出现灾难性遗忘：学新任务时，旧的记忆被全局扰动覆盖了。

人们不是不知道这些问题的存在，但它们此前被视为 MLP 的固有代价——要通用性就必须忍受不可解释性，要可解释就得转向决策树或线性模型，牺牲表达能力。KAN 问的是另一个问题：有没有一种网络结构，让「学了什么」天然就是可解释的，不用事后补救？

## 它真正看见了什么

**这篇论文的核心判断是：把可学的非线性函数放在网络的边上而不是节点上，网络的结构就会和它学的公式同构——剪掉哪些边，就等于在公式里去掉了哪些项。**

要理解这个判断为什么成立，需要先补齐几个不熟悉的概念，但它们在论文里不是逐一介绍的条目，而是在同一个现象中彼此咬合。

### 从 MLP 到 KAN：非线性搬家

先看 MLP 到底长什么样。一层 MLP 做的事是：输入向量先乘以权重矩阵做线性组合，然后把结果送进一个固定的非线性函数（比如 ReLU），最后输出。非线性在节点上：每个神经元收到一堆线性组合的数值，拍一个 ReLU，吐出结果。

KAN 把这个安排倒过来了。非线性不在节点，在边上。每条边是一个独立的一维函数 φ(x)，由样条（B-spline）参数化。节点不做非线性变换，只做一件事：把连到自己身上的所有边传来的值加起来。

这个「非线性搬家」的后果可以用两个网络学乘法 `f(x, y) = xy` 的过程来感受。MLP 学乘法：用大量神经元通过 ReLU 的拐点去近似双曲面的弯曲——你能得到不错的近似，但网络内部是一堆拐点的叠加，读不出「它知道自己在做乘法」。KAN 学乘法：训练结束后，网络自动剪枝成一个 `[2, 2, 1]` 的结构。你再把每条边上学的函数画出来——两条边学的是恒等函数（x → x 和 y → y），另外两条边学的是平方函数。节点上的求和自然地产生了恒等式 `xy = ((x + y)² − (x² + y²)) / 2`。你不需要归因工具，直接看函数曲线就知道网络怎么算的。

### 样条（spline）的局部性为什么重要

这里需要解释样条到底是什么，以及为什么不能简单换成「可学习的 ReLU 放在边上」。

样条是一种用分段多项式拼接而成的光滑曲线。关键属性是局部性：改变样条在某个网格点上的系数，只会改变那个点附近一小段曲线的形状，远端的曲线纹丝不动。这和 ReLU 形成鲜明对比——ReLU 虽然也叫非线性，但它是一个全局函数，整个实数轴上都受同一个公式 `max(0, x)` 支配。

局部性直接解释了 KAN 为什么能在持续学习任务中避免灾难性遗忘。论文做了一个精巧的小实验：用 5 个高斯峰作为 1D 回归目标，但数据不是一次性给的，而是把每个峰附近的数据逐个阶段喂给网络。MLP 每学一个新峰，之前的峰就全乱了——因为 ReLU 的全局性让新数据的梯度修改了整条曲线。KAN 每学一个新峰，只在当前网格点附近的样条系数上做修改，已经学好的区域不受影响。

这个实验是`[2, 10, 1]` 的 KAN 对 `[2, 10, 1]` 的 MLP，不是大模型对小模型——同样的参数规模，同样的层数，区别仅仅是非线性的位置和局部性。

### 剪枝：让结构自己浮现

光把非线性放在边上还不够。一个未经训练的 KAN 每层每条边上都有一个样条，整张图是全连接的——你仍然读不出任何结构。剪枝是让公式现形的关键环节。

论文的做法分两步。第一步是稀疏化（sparsification）：在损失函数里加一个 L1 正则项，惩罚每条激活边上的幅度。那些对输出贡献不大的边的样条幅度会被压到接近零。第二步是剪枝（pruning）：训练一定步数后，把幅度低于阈值的边直接删掉，得到一个稀疏网络。两步循环几次，最后剩下的结构就是网络认为真正需要的计算图。

回到纽结理论的案例。输入是 17 个不变量，输出是签名。训练加剪枝后，网络自己把 `[17, 1, 14]` 的结构压成了一条清晰的模式：只有 μ_r（meridional translation 的实部）连接的边最粗，μ_i 和 λ 的边明显细得多，其他 14 个输入几乎看不到连接。你不需要跑任何归因算法，盯着 KAN 的可视化图就看见了——这和 DeepMind 用梯度显著度得到的结论高度一致，但来得直接得多。

更让人惊讶的是参数效率。DeepMind 的 MLP 用了约 30 万个参数才到 78% 准确率；KAN 只用约 200 个参数就到了 81.6%，而且把这 200 个参数的含义摊开给你看。

### 从函数曲线到符号公式

剪枝告诉你哪些变量重要、它们之间怎样组合，但每条边上仍然是数值样条——你可以画出来看形状，却还写不出符号公式。最后一步是自动符号回归（auto-symbolic regression）：对每条剩下来的样条函数，用一个候选函数库（sin、exp、多项式、tanh 等）去拟合它，看哪个符号形式能最紧凑地近似它的形状。

以纽结理论的签名预测为例，作者训练了几个不同深度的 KAN，然后从浅到深得到了不同复杂度的符号公式。最浅的 `[3, 1]` KAN 给出的公式类似 `-0.02 sin(4.98 μ_i + 0.85) + 0.08 |4.02 μ_r + 6.28| - 0.52 - 0.04 e^(...)`，测试准确率 62.6%，虽不完美，但你能看懂它在做什么。三层的 `[3, 2, 1]` KAN 给出了一个带分式结构的公式，准确率 84.0%，和人类数学家推出来的公式（`σ ≈ λ μ_r / (μ_r² + μ_i²)`）在数值上高度相关（r² = 0.997）。

这里有一个重要的分寸。KAN 自动发现的公式虽然在准确率上超过了人类推导的公式，但它们更复杂、更丑（充满三角函数和指数嵌套）。自动发现还不能完全替代人类数学家的审美和洞察——它更像一台「结构显微镜」：让你看见数据里的函数形状，然后把猜测公式的工作从大海捞针变成了「这个曲线看起来像个什么」。

### 把概念接成模型

现在可以把这些概念接成一个运行的模型了：

```text
输入变量
    │
    ▼
每条边上放一个可学的样条函数 (非线性在边上)
    │
    ▼ (L1 稀疏正则化)
无用的边被压到接近零
    │
    ▼ (剪枝)
网络变稀疏, 结构浮现
    │
    ▼ (符号回归)
每条剩余边的样条被拟合成 sin/exp/多项式等
    │
    ▼
输出 = 一个人类可阅读的符号公式
```

这个模型解释贯穿全文的同样现象：

**原锚点（纽结理论）**：17 个变量输入 → 稀疏化和剪枝后只剩 3 个变量有显著连接 → 符号回归得到 `σ ≈ f(μ_r, μ_i, λ)` 的近似公式 → 200 参数做到 30 万参数 MLP 做不到的事。

**区分邻近情况**：如果给一个 MLP 做同样的 17 变量任务，训练完你得到的是一堆矩阵乘法，没有任何变量重要性会自动浮现。你需要事后跑归因算法（gradient × input、integrated gradients 等），而不同的归因算法可能给出矛盾的结论——因为归因本质上是给黑箱画肖像，不同角度画出来不一样。KAN 不需要归因，结构本身就是答案。

**预测条件变化**：如果把稀疏化正则项关掉（λ = 0），KAN 仍然能学到不错的准确率，但网络会保持全连接。你看到一个 `[17, 5, 5, 14]` 的密网，每条边上都有函数——准确但不解释。这意味着 KAN 的可解释性不是免费的：它依赖你主动选择稀疏化，而稀疏化可能牺牲一点准确率来换取可读取的结构。论文的 Pareto 前沿实验已经显示了这一点——最小可读结构（准确率够用但非最优）和最优准确率结构（参数更多、更难读）之间存在权衡。

### 证据与分寸

论文为四个关键关系提供了证据：

**KAN 比 MLP 参数效率更高**（图 3.1）：在 5 个合成的 KA 可表示函数上，KAN 的 RMSE 随参数量的下降斜率（α ≈ 4）显著陡于 MLP（α ≈ 4/d）。作者自己标注这些函数是「已知有 KA 表示」的，因此这是对 KAN 最有利的测试——它没有声称 KAN 在所有函数类上都更高效。

**KAN 的样条局部性使其免于灾难性遗忘**（图 3.4）：1D 高斯峰的顺序学习实验——范围窄但现象清楚。这个结果目前只在低维（1D）上验证了，作者明确说「在更现实的设置中，尤其是高维情况，尚不清楚如何定义局部性」。

**KAN 具有可解释性，能发现符号公式**（表 3、表 4）：在纽结理论中用 200 参数发现的结果与人类专家一致，且发现了几个此前未知的候选公式。但自动发现的公式通常比人类推导的更复杂——符号回归找到了拟合曲线，但未必找到了最简单的因果解释。

**KAN 在 PDE 求解上比同规模 MLP 更准**（图 3.3）：2 层宽 10 的 KAN（约 100 参数）在 Poisson 方程上的 MSE 比 4 层宽 100 的 MLP（约 1 万参数）还低两个数量级。然而作者也坦率指出 KAN 的训练速度比 MLP 慢约 10 倍，且对比的真解是符号公式——这对擅长符号表示的 KAN 天然有利。

通读全文后，这最多说明：KAN 在函数本身可以紧凑分解为少量一维函数的组合时，比 MLP 更参数高效且天然可解释。它还没有说明：在高维数据（图像、文本）上，KAN 是否仍然比 MLP 或 Transformer 更高效；在小样本、噪声数据或分布外泛化上的行为；以及样条训练速度慢的问题能否工程化解决。

## 我能带走什么

以后看到一个神经网络给出判断，我先不急着信它的准确率，而会先问：它的内部结构能不能写成一个我能理解的命题？

具体来说有两个判断场景。

第一，当你面对一个需要「理解 why」而不只是「预测 what」的任务时——比如科学发现、医疗诊断、风控决策——应该优先考虑可解释的架构，而不是事后再对黑箱做归因。KAN 提供了一个标准：如果网络不能用远少于全连接规模的边来表达同一个函数，那么这个函数可能本身就没有紧凑的符号结构——这也是一个有信息量的结论。

第二，当你在比较两个模型的参数效率时，不妨多问一句：非线性在什么位置？MLP 把非线性放在节点上，意味着同一条边的左右两端共享同一个激活函数；KAN 把非线性拆到每条边上，意味着不同输入维度到不同输出维度的映射可以各有各的函数形状。这个区别在输入维度之间有结构性关系（乘积、比值、特殊函数）时才会显现，在输入只是像素或 token ID 时可能不构成优势——选择架构前，先判断你的输入变量的关系更像数学公式还是更像像素矩阵。
