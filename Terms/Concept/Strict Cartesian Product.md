## 📖 详细定义

数学上只有 **笛卡尔积**（Cartesian product），没有标准的“严格笛卡尔积”。“严格”是方法论语境里的限定词：把分类轴当成一个完整乘积，并额外要求：

1. **轴独立**：每个维度可以单独取值，互不决定；
2. **组合穷尽**：所有组合都被视为有效类别；
3. **互斥单格**：每个对象只能落进一个组合；
4. **标签稳定**：对象不会同时属于多个格子，也不会随时间换格子。

形式化地，两个集合的笛卡尔积是：

`A × B = {(a, b) | a ∈ A, b ∈ B}`

翻成人话：从 A 里取一个、从 B 里取一个，所有搭配都算一个合法类别。三个轴就是所有三元组。

**和论文的关系。** 论文的 When（预训练 / 后训练 / 推理时）、Where（参数 / 记忆 / 技能 / 协议）、How（off-policy / on-policy / 无梯度）看起来像三个轴，但它明确说三轴是“互补的分析视角，不是互斥类别”。一个方法可以同时有多个标签，也可以随时间迁移：TTRL 是“推理时 + 参数 + on-policy”，Reflexion 是“推理时 + 记忆 + 无梯度”，AgentEvolver 同时更新参数和记忆，SKILL0 则是“技能库 → 参数”的轨迹。用严格笛卡尔积，这些方法会被迫压进一个格子，丢掉重叠和迁移信息。

**图上的一个点，不是方法的全部。** 论文的 Figure 2 为了画图，只把每个方法放在最显著的轴/载体下一次；真正的信息在 Appendix C 的 profile 表里。这是“主标签约定”（primary-axis placement），不是“每个方法只有一个本质类别”的本体论。

```text
严格笛卡尔积：
  When × Where × How
  → 每个组合一个格子
  → 每个方法恰好一个格子

论文的 profile：
  When 可多标签
  Where 可多载体 / 可迁移
  How 可多机制
  → 一个方法可以是一条轨迹
```

**常见误区。**

- “有三个轴” ≠ “严格笛卡尔积”。轴可以只是分析视角。
- “格子空着” ≠ “没人做过”。可能这个组合本身无意义，或方法被主标签放到了别处。
- “图里只出现一次” ≠ “只有一个标签”。这是可视化约定。
- “笛卡尔积”本身不是贬义。全因子实验就需要它；问题只在于把非独立、可重叠、会演化的分类对象硬当成乘积。

## 实际应用

- **读综述/分类图**：先问三件事——轴是否独立？类别是否互斥？每个方法是否只有一个稳定标签？只要有一个否，就别把图当严格笛卡尔积，也别把空区域当研究空白。
- **读这篇综述**：那句“三轴不是严格笛卡尔积”是在提醒你，Figure 2 的二维平面 + 颜色只是压缩可视化；When/Where/How 是 profile 的三个坐标，不是一张完整的互斥乘积表。实际分类看 Appendix C。
- **做实验设计**：全因子实验（full factorial design）是严格笛卡尔积的正当用法：学习率 × batch size × 优化器，所有组合都跑，才能估交互效应。此时“每个组合一个格子”是优点，不是缺点。
- **做 taxonomy/评测维度设计**：如果对象天然多标签、会迁移，优先用 profile / 多标签 / 轨迹，而不是强行一格；否则会把“跨轴方法”误判成异常值。

## 🔗 相关概念（3 个）

- `笛卡尔积（Cartesian Product）`：父概念——所有有序组合的集合；“严格”额外加了互斥、穷尽、单格、稳定四个要求。
- `组合画像（Profile）`：替代方案——一个对象用多标签向量表示，允许跨轴和迁移；论文的 Appendix C 就是 profile 表。
- `全因子实验（Full Factorial Design）`：正当用法——因子独立时，跑完所有组合以估计主效应和交互效应；和“把演化对象硬塞进一格”是两回事。

## ⚖️ 优缺点

- **优点**：① 组合穷尽、边界清楚，便于索引和比较；② 空格子能直接暴露“没被覆盖的组合”；③ 在因子独立的实验设计里，它是估计交互效应的标准做法。
- **缺点**：① 假设轴独立、类别互斥，遇到多标签/跨轴方法会失真；② 把“空”误读成“缺”，可能制造伪研究空白；③ 丢掉时间维度和迁移轨迹；④ 对快速演化、边界交叉的领域，容易产生“看起来精确、实际过度简化”的分类。

## 适用边界

只在轴独立、类别互斥、对象标签稳定时，才适合把分类当成严格笛卡尔积。否则把它降级为“分析视角”，用 profile、多标签或轨迹表示；空区域只能当提问的起点，不能当研究 gap 的证据。
